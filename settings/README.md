# Нормативы (настройки разработчика)

Папка для JSON-выгрузок меню «Особый конструкторский отдел».

- **Выгрузить нормативы (JSON)** — сохраняет все текущие настройки (таблица техники и все параметры `CFG`) в файл `ecotank-settings-ГГГГ-ММ-ДД.json`. В Chrome/Edge открывается диалог сохранения: один раз выберите эту папку, дальше браузер будет предлагать её сам. В других браузерах файл попадает в «Загрузки» — перенесите его сюда.
- **Загрузить нормативы (JSON)** — применяет файл и сохраняет его в браузере. Значения ограничиваются теми же пределами, что и поля панели; неизвестные ключи и неверные типы отбрасываются.
- `default.json` — штатные нормативы текущей версии игры.
