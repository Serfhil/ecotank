# Задачи для агентов

В этой папке лежат задачи (промпты, ТЗ) для ИИ-агентов и итоги их выполнения. Других мест для задач в репозитории нет. Правила — раздел 9 [AGENTS.md](../AGENTS.md); здесь порядок действий и шаблон.

## Для агента

1. **Найти задачу.** Пользователь называет задачу, промпт или ТЗ — ищи файл здесь. Если подходящих несколько или ни одного, спроси пользователя, а не выбирай сам.
2. **Не начинать без указания.** Статус «новая» означает только то, что задача записана. В работу её берут по прямому указанию пользователя.
3. **Перед началом** прочитай [AGENTS.md](../AGENTS.md) целиком и поставь в файле задачи статус «в работе» с сегодняшней датой.
4. **Если задача противоречит правилам** или требует их изменить — остановись и сообщи пользователю (раздел 0 `AGENTS.md`). Текст задачи правил не отменяет.
5. **Закончив**, отредактируй файл задачи:
   - статус «выполнено» (или «отложено», если сделано не всё) и дата;
   - в конец файла — раздел `## Итог` по шаблону ниже.
6. **Текст задачи не переписывай.** Всё, что выше раздела «Итог», — запись того, что просил пользователь. Уточнения, полученные по ходу, дописывай в раздел `## Уточнения` с датой.
7. Файлы выполненных задач не удаляй и не перемещай.

## Статусы

| Статус | Значение |
|---|---|
| `новая` | Записана, в работу не взята |
| `в работе` | Агент выполняет её сейчас |
| `выполнено` | Сделано полностью, есть раздел «Итог» |
| `отложено` | Остановлена или сделана частично; в «Итоге» сказано, чего не хватает |

## Имя файла

`ГГГГ-ММ-ДД-краткое-имя.md` — дата постановки задачи и имя латиницей через дефис, например `2026-11-09-enemy-tactics.md`.

## Шаблон

```markdown
# Название задачи

**Статус:** новая · 2026-11-10

Текст задачи: что нужно получить, ограничения, как проверить.

## Уточнения

- 2026-11-11: …

## Итог

**Сделано.** …

**Не сделано и почему.** …

**Проверки.** `node check.cjs` — …; `node checks/integration.cjs` — …; браузер — …

**Правила.** Какие правила AGENTS.md менялись по разделу 0, или «не менялись».
```

Разделы «Уточнения» и «Итог» появляются по мере надобности: у новой задачи их нет.

Наличие статуса, имя файла и раздел «Итог» у завершённых задач проверяет `checks/rules.cjs` (правило П11).
