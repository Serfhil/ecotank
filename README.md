# EcoTank

Аркадные танчики в браузере: один файл, без зависимостей и сборки.

## Запуск

Откройте `index.html` в любом современном браузере.

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | движение |
| Мышь | прицел башни |
| ЛКМ / Пробел | огонь |
| ПКМ / E | рельсотрон (если есть заряд) |
| P / Esc | пауза |
| M | звук вкл/выкл |
| Enter | старт / рестарт |

## Особенности

- Процедурно генерируемая симметричная карта на каждой волне.
- Препятствия: кирпич (разрушается за 2 попадания), сталь (неразрушима), вода (непроходима для танков, снаряды летят над ней), деревья (скрывают танк от врагов).
- Три типа врагов: разведчик, солдат, тяжёлый танк. Ищут путь к игроку, простреливают кирпич, стреляют с упреждением.
- Бонусы: ремонт, скорострельность, тройной выстрел, щит и рельсотрон — одноразовый мгновенный луч, который пробивает кирпич и всех врагов на линии до стали или края карты (до 3 зарядов).
- Подбитые враги оставляют горящие обломки. Проедьте по ним, чтобы собрать металлолом: разведчик — 1, солдат — 2, тяжёлый — 4. Обломки исчезают при смене волны.
- «Настройки разработчика» в меню паузы: ХП, скорость, скорость снаряда, перезарядка и урон для каждого типа танка, плюс параметры бонусов, волн и эффектов. Есть читы (ремонт, бонусы, пропуск волны, режим бога). Настройки сохраняются в `localStorage`.
- Волны с нарастающей сложностью, очки и рекорд (сохраняется в `localStorage`).
- Звуки генерируются через Web Audio API, графика рисуется на Canvas.
