# EcoTank

Браузерный танковый экшн без зависимостей и сборки. Откройте `index.html` в современном браузере — сервер не нужен. При переносе игры копируйте всю папку.

Правила изменения проекта и рецепты «как добавить танк, бонус, сценарий» — в [AGENTS.md](AGENTS.md) (`CLAUDE.md` подключает его же). Задачи для агентов — в [prompts/](prompts/README.md). История изменений — в [CHANGELOG.md](CHANGELOG.md).

## Проверка

```
node check.cjs                  все наборы проверок и правила проекта, около 10 секунд
node checks/integration.cjs     длинный прогон симуляции во всех режимах
npx prettier --write js check.cjs checks scripts    форматирование перед сдачей
```

Проверки запускают игру в Node с подменой браузерных API. Они не оценивают звук на слух и внешний вид, поэтому правки интерфейса дополнительно смотрят в браузере.

## Игра

- **Обычный бой** — оборона базы от волн врагов. Поле: случайное («Манёвры»), из пресетов («Типовые операции»), готовая карта («Свой плацдарм») или кампания из последовательных уровней («Дорога к победе!»).
- **Сюжетная миссия «Расейняй, Литва»** — четыре волны на авторской карте без базы; противник прорывается к южным выездам.
- Враги: лёгкий, средний и тяжёлый танки с групповой тактикой, САУ, РСЗО Panzerwerfer 42, мотобригады-минёры и смертники в зелени.
- Танк игрока улучшается звёздами: Т-34 → ИС-2 → ИС-2-II. Бонусы появляются по таймеру рядом с игроком и союзниками.
- Редактор пресетов и редактор карт открываются со стартового экрана; свои карты экспортируются и импортируются в JSON.
- Меню паузы → «Настройки разработчика»: параметры техники и баланса, инструменты тестирования, выгрузка и загрузка настроек файлом (папка [settings/](settings/)).

### Управление

| Клавиша | Действие |
|---|---|
| W/S или ↑/↓ | Вперёд / назад по направлению корпуса |
| A/D или ←/→ | Поворот корпуса |
| Мышь | Прицел башни |
| ЛКМ / Пробел | Огонь |
| ПКМ (удерживать) | Курсовой пулемёт в сторону курсора |
| C (С) | Зарядить снаряд из НИИ в основное орудие |
| Shift | Ускорение на 2 секунды |
| R | Ремонт за металлолом (в миссии «Расейняй») |
| P / Esc | Пауза |
| M | Весь звук вкл/выкл |
| Enter | Старт / рестарт |

### Символы карт и пресетов

`.` пусто, `B` кирпич, `F` забор, `S` сталь, `W` вода, `T` зелень, `P` песок, `R` дорога, `D` кирпич, разрушенный на 75%, `L` зелень, разрушенная на 75%; в пресетах пробел — «не трогать». Старые `b`/`t` (кирпич/зелень с шансом 60%) читаются, но в палитрах их нет. Каталог символов — `CELL_CATALOG` в `js/world.js`.

## Структура

Классические скрипты с общей глобальной областью; порядок подключения задан в `index.html`. Файлы только объявляют данные и функции, игру запускает `bootGame()`.

```text
index.html             Разметка, стили, список скриптов и вызов bootGame()
maps.js                Готовые карты и порядок кампании
maps-ai.js             Тактическая разметка готовых карт (создаётся scripts/prepare-ai-markup.cjs)

js/util.js             Утилиты: случайность, углы, clamp
js/ui-text.js          Все тексты интерфейса (UI_TEXT)
js/config.js           Техника (KINDS), ступени танка (PLAYER_TIERS), баланс (CFG), выбор игрока (PREFS)
js/scenarios.js        Реестр сценариев и контракт «ядро ↔ сценарий»

js/world.js            Поле: клетки, проходимость, каталог символов, генерация, база, карты и пресеты
js/destruction.js      Геометрия пробоин и разрушение окружения
js/tanks.js            Создание и движение танков, физика корпуса, ступени, управление игроком
js/weapons.js          Снаряды, пулемёт, снаряд из НИИ, артиллерия, ракеты
js/damage.js           Урон, гибель, взрывы и обломки
js/pickups.js          Бонусы (ITEMS): подбор и появление
js/enemy-ai.js         Поведение врагов (ENEMY_AI), поля маршрутов, видимость, колонны, САУ, РСЗО
js/enemy-tactics.js    Групповая тактика обычных танков
js/allies.js           Союзники и подкрепление
js/waves.js            Состав волн и появление врагов
js/sappers.js          Мотобригады, мины, заряды и смертники
js/statistics.js       Счётчики операции

js/render-*.js, js/renderer.js, js/effects.js, js/vehicle-sprites.js   Отрисовка
js/layout.js           Геометрия поля и HUD
js/defeat.js, js/victory.js   Экраны поражения и победы
js/audio.js            Музыка и звуковые эффекты
js/editor-common.js, js/preset-editor.js, js/map-editor.js   Редакторы
js/settings.js         Сохранение настроек и панель разработчика
js/menu.js             Главное меню и синхронизация DOM
js/game.js             Состояние боя, ввод, игровой цикл, bootGame()

js/scenario-waves.js   Сценарий «обычный бой и кампания»
js/raseiniai*.js       Сценарий «Расейняй»: логика, карта, интерфейс

check.cjs, checks/     Проверки (checks/rules.cjs — автоматическая часть правил)
scripts/               Подготовка спрайтов и тактической разметки
assets/                Изображения, музыка, CSS
settings/              Папка для выгруженных настроек разработчика
docs/                  Проектные документы
prompts/               Задачи для агентов и их итоги
```

## Сохранения

Всё хранится в `localStorage` браузера: рекорд, свои карты и пресеты, прогресс кампании, выбор режима. Из настроек разработчика сохраняются только значения, изменённые относительно `js/config.js`; остальные всегда берутся из файла.
