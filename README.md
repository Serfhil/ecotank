# EcoTank

Аркадные танчики в браузере: один файл, без зависимостей и сборки.

## Запуск

Откройте `index.html` в любом современном браузере.

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | движение |
| Мышь | прицел башни |
| ЛКМ / Пробел | огонь |
| P / Esc | пауза |
| M | звук вкл/выкл |
| Enter | старт / рестарт |

## Особенности

- Процедурно генерируемая симметричная карта на каждой волне.
- Препятствия: кирпич (разрушается за 2 попадания), сталь (неразрушима, от неё один раз рикошетят ваши снаряды), вода (непроходима для танков, снаряды летят над ней), деревья (скрывают танк от врагов).
- Три типа врагов: разведчик, солдат, тяжёлый танк. Ищут путь к игроку, простреливают кирпич, стреляют с упреждением.
- Бонусы: ремонт, скорострельность, тройной выстрел, щит.
- Волны с нарастающей сложностью, очки и рекорд (сохраняется в `localStorage`).
- Звуки генерируются через Web Audio API, графика рисуется на Canvas.
