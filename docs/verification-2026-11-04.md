## Как повторить

Из папки `ecotank`:

```powershell
node check.cjs
node scripts/check-integration.cjs
```

Второй скрипт — дополнительная интеграционная проверка. Она использует модель браузерных API и фиксированный генератор случайных чисел, не открывает сеть и не изменяет файлы игры. Игрок временно неуязвим, а здоровье базы увеличено, чтобы довести каждый сценарий до конца. Гибель игрока и базы проверяется отдельно. Запуск требует Node.js; установки пакетов не требуется.

## Границы проверки

- Проверка в браузере выполнена через временный HTTP-сервер на 127.0.0.1. Прямой запуск file:// не проверялся: доступ к нему ограничен политикой инструмента браузера. Статическая совместимость с открытием index.html сохранена; ES-модули, fetch и сборщик не добавлены.
- Прогон симуляции не является замером реального FPS. Производительность массовых взрывов и качество звука на слух в этой проверке не оценивались.
- Это локальная проверка. Опубликованная версия сайта и другие браузеры/устройства не проверялись.
- Основные подсистемы разнесены по файлам, но общее состояние, ввод, DOM-меню и игровой цикл ещё остаются в index.html. Полной изоляции модулей пока нет.
