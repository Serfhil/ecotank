# Слои техники

Производные исходных `output/imagegen/*-sprite.png`, подготовленные с разрешения пользователя программно, после отказа генератора. Исходники не перезаписываются.

| Префикс | Модель |
|---|---|
| t34-player | Т-34, игрок/союзник без улучшений |
| is2-player | ИС-2, первое улучшение |
| is2-ii-player | ИС-2-II, второе улучшение |
| pzkpfw-iii-scout | Pz.Kpfw. III (лёгкий) |
| panther-soldier | Pz.Kpfw. V Panther (средний) |
| tiger-heavy | Pz.Kpfw. VI Tiger (тяжёлый) |
| ferdinand-artillery | Ferdinand (САУ), закрытая неподвижная рубка |

`-hull.png` — корпус без башни, ствола и видимых траков (192×224); `-turret.png` — башня (128×128), отсутствует у Ferdinand; `-gun.png` — одно орудие (36×192), у ИС-2-II используется дважды; `-tracks.png` — четыре вертикальные фазы (24×896).

В игре заданы явные размеры: корпус 32×35 локальных единиц, башня 23–27×24, орудия 30/35/28 для игрока, 30 для танков противника и 35 для САУ. Точка башни игрока и улучшенных союзников смещена вперёд на 5 локальных единиц. Масштабы из tankScale применяются один раз, уширение ИС-2-II — отдельно по поперечной оси.

Все PNG — RGBA, содержат полностью прозрачные и непрозрачные пиксели. Контуры обрезаны по явным маскам, свечение вне техники исключено. Скрытая ранее палуба под башней восстановлена в цвет корпуса с кольцом крепления. Скрипт подготовки хранит исходные контуры и прямоугольники в явном виде; не выводит игровые размеры из прозрачных полей.

Атласы нарезаны из `suiside-and-motocycle-RAW.png` скриптом `scripts/prepare-miner-sprites.py`: фон с альфой ниже 128 (шум и красный ореол) удалён, края оставлены жёсткими. Все кадры смотрят вверх, как слои танков.
